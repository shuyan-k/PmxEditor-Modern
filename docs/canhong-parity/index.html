修复内容（本轮）
  • 物理爆炸根因：C++ 回写骨骼时使用“帧开始前的父骨骼世界矩阵”缓存，而 Python 版按 eval_order 逐骨累积世界矩阵。多级链（袖 / 裙 / 发）每深一层都会把父级位移再叠加一次，误差逐帧放大 → 布料被拉成巨面片。
  • 修复方式：Physics::step 改为按求值顺序逐骨累积 bone_world，与 Python 的 physics_step 完全同构；BF_AFTER_PHYSICS 骨骼仍参与累积但不写 override。
  • 顺带修复：物理每步之前会丢失骨骼形态，现改为 step(pose, dt, &morph_weights) 并显式 pose.apply(weights)。
  • 交互补齐：设置页新增「物理演算」复选框（与 P 键等效），检查器默认宽度由 400 → 560，10 个标签不再被滚动箭头遮挡。
